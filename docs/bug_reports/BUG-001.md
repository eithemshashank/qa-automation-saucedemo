# BUG-001: All products show the same placeholder image for `problem_user`

| Field | Value |
|---|---|
| Severity | Minor (visual, ordering still possible) |
| Priority | Low |
| Status | Open (confirmed 2026-10-19) |
| Environment | https://www.saucedemo.com, Chromium (Playwright 1.64), Windows |
| User | `problem_user` / `secret_sauce` |
| Found by | `tests/test_problem_user.py::test_each_product_has_its_own_image` |

**Steps to reproduce**
1. Open https://www.saucedemo.com.
2. Log in as `problem_user` with password `secret_sauce`.
3. Look at the product images on the products page.

**Expected result:** each of the 6 products shows its own image.

**Actual result:** all 6 products use the same image file, `/assets/sl-404-Cq1a9k9X.jpg` (a "not found" placeholder).

**Evidence:** the test collected the `src` of the 6 product images; there was 1 distinct value for 6 images.

**Note:** `problem_user` is a deliberately faulty account provided by the site for testing practice.
