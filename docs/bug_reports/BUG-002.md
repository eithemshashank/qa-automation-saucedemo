# BUG-002: Sorting has no effect for `problem_user`

| Field | Value |
|---|---|
| Severity | Major (a core feature does not work) |
| Priority | Medium |
| Status | Open (confirmed 2026-10-19) |
| Environment | https://www.saucedemo.com, Chromium (Playwright 1.64), Windows |
| User | `problem_user` / `secret_sauce` |
| Found by | `tests/test_problem_user.py::test_sort_price_low_to_high_works` |

**Steps to reproduce**
1. Log in as `problem_user` with password `secret_sauce`.
2. Note the order of the product prices.
3. Open the sort dropdown and choose "Price (low to high)".

**Expected result:** prices are shown in ascending order: 7.99, 9.99, 15.99, 15.99, 29.99, 49.99.

**Actual result:** the order does not change.

| | Prices in page order |
|---|---|
| Before sorting | 29.99, 9.99, 15.99, 49.99, 7.99, 15.99 |
| After "low to high" | 29.99, 9.99, 15.99, 49.99, 7.99, 15.99 |

**Comparison:** the same sort works correctly for `standard_user` (TC-08 passes).

**Note:** `problem_user` is a deliberately faulty account provided by the site for testing practice.
